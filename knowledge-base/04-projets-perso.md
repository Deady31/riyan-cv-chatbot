# Projets personnels

Point commun de tous ces projets : ce sont des outils que Riyan est amené à utiliser lui-même au quotidien — approche "je construis ce dont j'ai besoin", validation d'hypothèses par l'usage réel plutôt que par la théorie.

## Bot de scraping offres d'emploi
Scrape en continu les offres de VIE (Business France), HelloWork, Welcome to the Jungle. Envoie les nouvelles offres dans différents channels Discord, alertes toutes les 2 heures. Hébergé sur GitHub. Utilisé personnellement pendant sa recherche d'emploi.

## Overwatch Nexus — outil de counter-pick
Outil permettant de sélectionner la map et les héros adverses en face, et qui génère des recommandations de héros à pick pour contrer l'équipe adverse. Projet lié à son intérêt pour les jeux vidéo compétitifs et les mécaniques d'engagement.
Stack : deux applications dans le même repo — un frontend web en Next.js (`overwatch-nexus-web`) et un dashboard en Python/Streamlit.
Code source : https://github.com/Deady31/Overwatch-Nexus

## Cineappmovies — application films à l'affiche
Application web qui recense les films en salle et en streaming autour de l'utilisateur, avec filtres par plateforme (Cinéma, Netflix, Prime Video, Disney+), tri (date, popularité, note), fiches détaillées (synopsis, durée, casting, bande-annonce) et recommandations de films similaires.
Stack : Next.js, React, TypeScript, Tailwind CSS. Double intégration API : l'API TMDB pour les données films généralistes, et une API Pathé reverse-engineerée avec l'aide d'un agent IA (l'agent a exploré et testé les requêtes du site Pathé pour en extraire un accès fonctionnel aux séances par cinéma) pour les horaires de séances en temps réel.
Code source : https://github.com/Deady31/Cineappmovies

## Invoicity
Application de facturation pour artisan. Solution de gestion de devis et factures conçue à partir de besoins réels observés. UX simplifiée, conception orientée utilisateur final.

## POC IA — MVPs fonctionnels via IA générative
Développement rapide d'applications fonctionnelles via structured prompting, Claude, Cursor et outils no-code IA. Approche itérative orientée validation d'hypothèses plutôt que développement long.
